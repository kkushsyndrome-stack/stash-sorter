### New: Launch tab
Change the command line arguments Battle.net passes to D2R (Battle.net → Game Settings → Additional command line arguments) with tick boxes instead of typing them:
- `-direct -txt`, `-enablerespec`, `-resetofflinemaps`, `-mod` (lists the mods you have installed), plus anything else you type.
- Typos are pointed out, like `txt` without its dash or a `-seed` that isn't a number.
- Only D2R's arguments change, and a copy of the previous settings is kept, with **Put these back**. Saving needs Battle.net to be closed, because it overwrites the file when it exits.
- **Launch D2R** starts the game through Battle.net.

### New: Seed runs and favourite seeds
Give a character a particular offline map without leaving `-seed` in place (left in, it makes the game's random numbers predictable).

Press **▶ Seed run** and follow the steps. The tab notices on its own when D2R and Battle.net open and close:
1. Close D2R and quit Battle.net. The seed goes in.
2. D2R starts with `-seed`. Load the character, enter a game, then Save & Exit and close D2R.
3. Quit Battle.net again. The seed comes off and D2R starts normally. The character keeps the map.

It shows which characters were saved during the seeded game, and offers **Start with the seed again** if none were. If you close Stash Sorter partway through, it finishes the run and takes the seed off the next time it starts.

**Favourite seeds**: keep the seeds you like, each with a name, what it's for (Cows, Pit / Tombs, Chaos…) and notes, and start a seed run from any of them with one click.

In the terminal: `StashSorter.exe launch-args`, `StashSorter.exe launch` and `StashSorter.exe seed-run 1234567`.

### Also
- The version number now shows next to the title.
- `Stash Sorter.bat` (for running from source) runs the code in its folder instead of an older `dist\StashSorter.exe`.

Good to know: quit Battle.net from its icon next to the clock (right-click → **Exit**). Closing its window only hides it.

**New to Stash Sorter?** Download `StashSorter.exe`, put it in its own folder, close the game completely and double-click it. Windows may warn about an unrecognised app (the exe isn't code-signed): *More info → Run anyway*. You can check the download against `StashSorter.exe.sha256`. Offline saves only.
