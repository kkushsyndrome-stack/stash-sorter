# Horadric Toolkit 0.8.0

Horadric Toolkit brings stash management, item browsing, session tracking, and game launch tools together in one local
app. It replaces the Stash Sorter name; existing saves, backups, rules, and settings remain in place.

### New

- **Change item appearance** for rings, amulets, charms, and jewels without changing their stats.
- **Item Art** can change item pictures and body-armour looks using the game's extracted files. Original files are
  backed up and can be restored.
- **Session tracker** records runs, item gains and losses, experience, levels, and gold while you play.
- **Launch options** manage Battle.net arguments, saved map seeds, and one-game seed runs.
- **Terror Zones** show the active and upcoming zones and can set and restore the Windows clock.

### Also

- Rename any character, create mules, and manage characters' personal stashes alongside the shared stash.
- The app, Windows launcher, command line, and release executable now use the Horadric Toolkit name.

Offline characters only. See the README for setup and safety details.
