Item levels

What each item's item level means, from the game's own affix tables. Craft bait (magic rings & amulets): crafted item level = ⌊crafter level ÷ 2⌋ + ⌊ingredient ilvl ÷ 2⌋, so craft with a high-level character. Reroll: "3 perfect gems + magic item" keeps the item level. Bases: how many sockets the item level allows. As-is flags magic items already worth keeping (best-tier valuable affixes).

Duplicates

Unique and set items you have more than once, with every copy's stats so you can keep the best roll. Tick the copies you want to delete. Equipped items can't be deleted here (take them off in game first). Deleting is backed up and can be undone from Backups.

Empty mules

Mules with nothing worth keeping: nothing in their stash, inventory or cube, no gold, no mercenary, only their starting gear. Run Sort & Distribute → Tidy up first to pack your loot onto as few mules as possible. Deleting removes the character's save files (backed up, and undoable from Backups).

Backups

A full copy of your save folder is zipped before every change. Undo reverses just that one change (only possible while the files it touched are unchanged); Restore puts the whole folder back as it was. Both back up the current state first.
